# Интерактивы и вероятностные кандидаты: Кноп 2011, часть 1

## Интерактивные кандидаты

- `polygon-side-binary-search-by-diagonals`: геометрический тренажер, где пользователь выбирает диагональ 7- или 8-угольника, а скрытая сторона отвечает одной из двух частей.
- `chessboard-cell-rectangles-six-questions`: доска 8x8/5x5, выбор прямоугольника и ответ да/нет; полезно для проверки стратегий разбиения.
- `divisibility-guess-number-1-to-8-three-questions`: дерево вопросов по делимости; тип близок к конечному бинарному протоколу с ограниченным набором допустимых вопросов.
- `yes-no-dont-know-one-question-three-numbers`: мини-интерактив на конструирование одного трехисходного вопроса; нужен отдельный тип, потому что ответ «не знаю» зависит от смысла вопроса, а не от заранее заданной таблицы.
- `function-sign-change-interval-value-queries`: пограничный интерактив для value-oracle/bisection; пользователь выбирает точки, движок отвечает знаками или значениями функции, adversary-режим должен сохранять хотя бы один совместимый отрезок смены знака. Делать только после доводки карточки: сейчас `public_ready:false`, нижняя оценка требует проверки.
- `cowboy-target-by-closer-shot-comparisons`: непрерывный поиск цели по сравнению двух последних выстрелов; интерактив пригодится только после проверки точного решения.
- `different-size-card-piles-two-questions`: песочница для раскладок на стопки разных размеров и проверки, что пары ответов различают карты.

## Не требуются отдельные интерактивы

- `product-60-pair-three-yes-no-questions`, `even-odd-pair-1-to-10-five-questions`, `unordered-triple-1-to-10-eight-questions`: покрываются общим конечным бинарным деревом или карточкой `fixed-questions-as-binary-code`.
- Частные случаи занятия 1 про обычное угадывание чисел/слов лучше оставлять вариантами общей двоичной емкости.

## Вероятностный слой

- Для обычного угадывания чисел из занятия 1 естественный будущий слой: при заданном априорном распределении выбрать вопросы, минимизирующие среднюю длину дерева решений. Это не отдельная probability-only карточка, а вероятностная версия уже имеющихся протоколов угадывания.
- Для `product-60-pair-three-yes-no-questions` и `even-odd-pair-1-to-10-five-questions` можно позже рассмотреть оптимальное дерево при неравномерном распределении пар.
- Для `cowboy-target-by-closer-shot-comparisons` вероятностный вариант может быть связан с априорным распределением цели на квадрате и минимизацией ожидаемой ошибки, но это требует отдельной математической постановки.
