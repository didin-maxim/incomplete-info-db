# four-guineas-exactly-two-counterfeits-verification

Сделан сильный интерактив `property_verification_balance` для проверки свойства, а не для поиска всех весов.

Модель: 4 монеты, два возможных веса, 16 скрытых бинарных распределений. Финальный ответ только булевый: распределение 2+2 или нет. Состояния 0+4, 1+3, 3+1, 4+0 отвергаются.

Режимы:
- `random`: фиксирует случайное скрытое состояние и проверяет, вынужден ли ответ после действий пользователя.
- `cheater`: выбирает исход взвешивания, который сохраняет наибольшую неоднозначность.
- `exhaustive`: пользователь строит дерево решений; каждая ветка по всем возможным исходам должна вынудить ответ `ровно две` или `нет` за два взвешивания.

Ограничение: движок намеренно не требует назвать настоящие и фальшивые монеты, потому что цель карточки - сертифицировать свойство.
