# Ревизия простых кодовых интерактивов

Дата: 2026-05-25.

Критерий этой ревизии: сильный интерактив есть только там, где пользователь сам строит проверку, кодовую таблицу, ход или стратегию, а viewer проверяет результат. Если пользователь в основном нажимает кнопку готовой схемы, выбирает ответ из уже раскрытой таблицы или смотрит перебор, это демонстрация или кандидат на редизайн.

Слова `binary`, `ternary`, `code` не должны быть нужны для первого прохода. Для младших и 5-7 классов достаточно говорить "да/нет", "три ответа", "три кучки", "карточки", "порядок", "пароль", "после стирания". Термины можно вводить после действия.

## Итоги

Сильные простые упражнения:

- `fixed-questions-as-binary-code`
- `balanced-subset-8-three-questions`
- `password-feedback-permutation-variant`
- `xor-8-coins-one-flip`
- `permutation-encodes-six-messages`
- `three-letter-erasure-4-bit-code`

Сняты из public / требуют редизайна:

- `one-counterfeit-among-27-three-ternary-questions`
- `calgary-jmc-2021-b3-password-feedback`

Честные демонстрации:

- `calendar-card-binary-trick`
- `twenty-one-card-trick`
- `fitch-cheney-five-card-trick`

Кандидаты на будущий редизайн:

- `three-letter-erasure-4-bit-code`: повторно проверить видимость в `random`; если есть утечка, скрыть ее до ответа.
- `one-counterfeit-among-27-three-ternary-questions`: дать строить три разбиения или кодовую таблицу.
- `calendar-card-binary-trick`: дать собрать собственные карточки, а не только читать готовые.
- `fitch-cheney-five-card-trick`: добавить режим ассистента без автопостроения хода.
- `permutation-encodes-six-messages`: дать пользователю задать соответствие "сообщение -> порядок".

Общий вывод совпадает с отдельными выводами по `password-feedback-permutation-variant` и `one-counterfeit-among-27-three-ternary-questions`: сильным считается не тот UI, где видна красивая таблица, а тот, где пользователь сам предъявляет проверяемую стратегию.
