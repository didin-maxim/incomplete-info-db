# Обзор интерактивов про видимость колпаков и скрытых состояний

Дата: 2026-05-22.

## UX-шаблон

Для задач, где один пользователь сайта временно играет участника с ограниченным обзором, интерактив должен явно разводить три режима.

- `Глазами участника i`: показывать только наблюдение этого участника. Собственный колпак, собственный бит, спрятанный номер, ключ, исходная раскладка другого этапа и полный скрытый набор маскируются.
- `Проверка стратегии`: перебирает скрытые расклады или классы раскладов без раскрытия конкретного скрытого состояния до завершения проверки.
- `Внешний наблюдатель`: допускает полный расклад, таблицы кодов и готовые ответы только как разбор после ответа или как явно подписанный демонстратор.

Полный перебор должен быть обозримым: показывать классы, агрегаты или формулу числа состояний, а не только одно большое число.

## Реализованная переработка

Для `wise_men_even_parity_code` и `wise_men_color_count_parity_protocol` добавлен режим выбранного мудреца:

1. Полный скрытый расклад хранится в модели, но в UI выбранного мудреца его колпак показывается как `?`.
2. До проверки показываются только чужие колпаки и разрешенные публичные данные: биты в первой задаче, два допустимых варианта цвета во второй.
3. Пользователь вводит ответ выбранного мудреца; настоящий цвет, полный код, полные количества и ответы всех участников раскрываются только после проверки.
4. Exhaustive показывает агрегаты: число расстановок/восстановлений для битового кода и число расстановок, минимум/максимум верных ответов, классы четности для цветовых количеств.

## Итог ревизии

После переработки утечки информации не оставлены как полноценные интерактивы: `wise-men-6-32-colors-one-bit` и `wise-men-6-four-colors-permutation-parity` теперь требуют активного ответа пользователя в режиме ограниченной видимости, а демонстрационный разбор отложен до проверки. В `prisoners-hats-parity-line`, `wise-men-6-hidden-hat-number-parity`, `prisoners-10-boxes-cycle-strategy` и `xor-8-coins-one-flip` текущая UX-модель соответствует ограниченной видимости или раскрывает полный мир только после проверки.
