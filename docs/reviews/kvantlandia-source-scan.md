# Скан источников Квантландии

Дата: 2026-05-23.

## Проверенные источники

- `https://kvantland.com/`: официальный сайт проекта. Подтверждены онлайн-турниры, разделы задач и ссылки на математические турниры.
- `https://math.kvantland.com/`: страница математического турнира. Открыты даты турниров 2025/2026 и один публичный пример, но полные задачи требуют входа/регистрации.
- `https://t.me/s/kvantland`: публичное зеркало Telegram-канала открывается без входа и содержит условия отдельных задач.
- `https://t.me/s/kvantland/949`, `https://t.me/s/kvantland/1079`: анонсы финального турнира сезона 2025. Найдены только названия задач, включая «Говорящие карточки» и «Лжецы в школе», без условий.
- `https://t.me/s/kvantland/581`: пост «Мудрецы за круглым столом» с задачей про 100 мудрецов и колпаки.
- `https://t.me/s/kvantland?before=98`: пост с задачей М. Островского про число от 1 до 55 и платные ответы.

## Добавлено

- `kvantland-wise-men-100-hats-at-least-one`: строгая задача о заранее согласованной стратегии; решение через суммы по модулю и оценку покрытием.
- `kvantland-ostrovsky-paid-questions-55`: оптимальная стратегия вопросов с разной ценой ветвей; решение через фибоначчиеву емкость дерева решений.

## Не добавлено

- Публичные примеры сайта и большая часть постов канала про геометрию, комбинаторику, вероятность и устный счет: вне темы базы.
- Посты про круговых рыцарей/лжецов с подсчетом типов: часть задач статическая, без построения стратегии; часть близка к уже существующим карточкам и требует отдельной проверки дублей.
- Закрытые турнирные задачи с сайта: условия не извлекались без доступа к аккаунту.

## Дубли и родство

- Для задачи про 100 мудрецов найдены родственные карточки `hat-line-k-colors-modulo` и `ebert-seven-hats-hamming-code`; дубля одновременной цели «хотя бы один угадает» не найдено.
- Для платных вопросов найден базовый родственник `twenty-questions-binary-search`; дубля с ценами «да» = 2, «нет» = 1 не найдено.
