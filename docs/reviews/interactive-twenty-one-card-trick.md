# Интерактив: фокус с 21 картой

Добавлен интерактив `twenty_one_card_trick` для карточки `twenty-one-card-trick`.

## Модель

- 21 карта раскладывается в 3 столбца по 7 карт.
- В каждом раунде зритель сообщает столбец выбранной карты.
- Сбор выполняется так, что указанный столбец становится средней стопкой.
- После трех раундов ответ берется из центральной позиции колоды, позиции 11.

## Режимы

- `random`: система выбирает скрытую карту; пользователь может дать столбцы вручную или нажать ответ зрителя.
- `manual_spectator`: пользователь сам выбирает карту и отвечает за зрителя.
- `exhaustive`: движок проверяет все 21 возможные карты.

## Проверки

Самотест покрывает полный перебор всех карт, отдельные трассы и порядок сбора стопок.
