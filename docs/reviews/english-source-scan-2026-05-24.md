# English Source Scan, 2026-05-24

## Reviewed Sources

- MathCircles.org / MfA Utah, Paul Zeitz, `Mathematical Magic for Muggles`: rich and clean. It has statements and a revealed-solutions section. Added two new cards and merged one duplicate source.
- Tanya Khovanova's Math Blog, `Weighings` category and `Gold, Silver, and Bronze Coins`: rich, current, and discussion-heavy. Added one new adaptive subset-test problem from the post plus comment solution.
- UKMT competition archive and extended solutions: official and clean, but the matching truth/liar examples found in this pass are already represented by existing UKMT/AMC cards or too small to justify a new card.
- AoPS Wiki, `KGS math club`: large community archive with some high-value protocol puzzles, but quality and completeness vary. Treated as candidate source, not imported in this pass.
- MAA review, `The Mathematics of Coordinated Inference`: useful map of the hat-guessing/coordinated-inference literature, not a problem archive with standalone solutions.

## Added Cards

- `math-muggles-fingers-that-can-see`: blind card-orientation invariant. Interactive: possible but not needed; the invariant is one-step.
- `math-muggles-concentration-parity-grid`: single flipped card in a parity grid. Interactive: possible and useful; good small syndrome-checking exercise.
- `khovanova-2025-gold-silver-bronze-magic-bag`: one fake coin of each metal, five adaptive yes/no tests. Interactive: needed/possible, but needs a custom model for "test glows iff it contains all hidden coins".

## Useful Duplicates

- `fitch-cheney-five-card-trick`: Zeitz's `Mind-Reader?` from `Mathematical Magic for Muggles` is the same Fitch Cheney trick; added the source to the existing card instead of creating a duplicate.
- Zeitz `More Hats`: duplicate of the standard line-of-prisoners parity protocol; not added.
- Zeitz `Buried in the Sand`: classical waiting/silence hats problem; not added in this pass because it is a short classic variant and lower priority than richer coding cards.

## Not Added

- Khovanova alternator/chameleon/random-scale posts: on topic and promising, but likely overlap with Knop/LKTG material already in the database and need a separate pass.
- AoPS KGS `100 prisoners boxes`: already represented by `prisoners-100-boxes-cycle-strategy`.
- AoPS KGS infinite hats/dwarfs: promising, but advanced infinite-protocol problem; left unchecked for the next agent.
- UKMT IMC/SMC truth-liar snippets: official, but mostly short variants or already covered mechanisms.
