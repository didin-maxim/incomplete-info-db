# Handoff For New Chat

Новая база лежит здесь:

`C:\Users\Admin\Documents\Codex\incomplete-info-db`

Это файловая база задач про неполную информацию: взвешивания, мудрецы, общие
знания, карточные фокусы, вопросы с ложью и доказательства невозможности.

## Источник истины

Главный источник истины - `data/`.

Особенно важны:

- `data/problems/` - карточки задач и лемм
- `data/relations/` - межкарточные связи
- `data/sources/` - источники
- `data/definitions/` - определения
- `data/standard_ideas/` - повторяемые идеи стратегий
- `data/taxonomy/` - фрагменты, теги, статусы, типы связей
- `data/comments/` - комментарии ревьюеров

Производные артефакты:

- `viewer/index.html`
- `docs/index.html`, если скопирован viewer для публикации
- `index/generated.sqlite`

## Минимальный цикл

```powershell
python tools\validate.py
python tools\check_links.py
python tools\audit_rules.py
python tools\build_index.py
python tools\build_viewer.py
python tools\search.py query "кодирование"
```

## Что важно не ломать

1. Не редактировать viewer и SQLite как источник истины.
2. Не класть неполную стратегию в `strategies[]`.
3. Для оптимальных задач фиксировать не только стратегию, но и нижнюю оценку.
4. Для взвешиваний заполнять `weighing_profile`.
5. Для вопросов с ложью заполнять `questions_profile`.
6. Добавлять связи только при общем информационном механизме.

## Стартовый корпус

В первой версии добавлены 8 карточек:

- 12 монет за 3 взвешивания
- 9 монет за 2 взвешивания
- невозможность найти тяжелую монету среди 4 за 1 взвешивание
- грязные дети и общее знание
- заготовка для трех мудрецов со шляпами
- фокус Фитча-Чейни с пятью картами
- бинарное угадывание числа
- нижняя оценка для вопросов с одной ложью

Главная следующая работа - расширять корпус и уточнять фрагментные профили на
реальных олимпиадных задачах.
