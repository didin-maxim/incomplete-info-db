# incomplete-info

Черновая база олимпиадных и классических задач про неполную информацию:
взвешивания, мудрецов, общие знания, карточные фокусы, стратегии вопросов,
кодирование сообщений и доказательства невозможности.

База устроена по образцу `graph-db`: источником истины являются JSON-совместимые
YAML-файлы в `data/`, а viewer и поисковый индекс собираются из них.

## Что внутри

- `data/problems/` - карточки задач, теорем, лемм и стандартных стратегий
- `data/relations/` - связи между карточками, в том числе между разными фрагментами
- `data/sources/` - нормализованный реестр источников
- `data/definitions/` - стандартные определения
- `data/standard_ideas/` - стандартные идеи стратегий и нижних оценок
- `data/taxonomy/` - словари фрагментов, тегов, статусов и типов связей
- `data/comments/` - отдельные комментарии ревьюеров
- `data/import_batches/` - журналы массовых импортов
- `tools/` - проверка, поиск и сборка viewer
- `viewer/index.html` - статический viewer

## Фрагменты

База намеренно фрагментирована. У всех карточек есть общий
`incomplete_information_profile`, а у некоторых фрагментов есть свои поля:

- `weighing_profile`: число взвешиваний, модель весов, число монет, тип фальшивки;
- `knowledge_profile`: агенты, публичные объявления, глубина общего знания;
- `card_trick_profile`: размер колоды, размер руки, скрытые/передаваемые карты;
- `questions_profile`: число вопросов, допустимые ответы, число лжи;
- `communication_profile`: канал связи, мощность сообщения, кодирование.

Фрагментные поля нужны для точного поиска внутри блока. Родственные связи при
этом могут соединять задачи из разных фрагментов, если совпадает реальный
механизм: разбиение пространства состояний, код с исправлением ошибок,
симметрийная стратегия, общий индукционный ход по знанию и т.п.

## Быстрый старт

```powershell
python tools\validate.py
python tools\check_links.py
python tools\audit_rules.py
python tools\build_index.py
python tools\build_viewer.py
python tools\search.py query "взвешивания"
python tools\search.py neighbors counterfeit-12-coins-3-weighings --depth 2
python tools\comments.py --status open
```

После сборки viewer можно открыть `viewer/index.html`.

## Текущее состояние

Это первая версия структуры. Корпус маленький и служит для проверки схемы:
несколько классических задач по взвешиваниям, знаниям, карточному фокусу и
вопросам с ложью. При дальнейшем наполнении важнее сохранять качество карточек,
чем быстро наращивать количество.
